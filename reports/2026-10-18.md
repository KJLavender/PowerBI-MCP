## 6. 判斷方式與指標定義

- **顯著**：變化量與該序列自身過去半年的正常波動相比，超過門檻個標準差（z 值；整體 ≥ 3.0，維度成員 ≥ 4.0），且幅度夠大。7 日與 28 日的比較已扣除去年同期的季節性變化。
- **範圍取捨**：若「A × B」的變化扣除後，B 的其餘部分都沒有變化，就只報告 A × B；若其他成員也同向變動，則報告較大的範圍。

| 指標 | 說明（Power BI 模型） | DAX |
|---|---|---|
| 銷售額 | 折扣後淨銷售額 | `SUM ( FACT_SALES[SALES_AMOUNT] )` |
| 毛利率 | 毛利 ÷ 銷售額 | `DIVIDE ( [毛利], [銷售額] )` |
| 訂單數 | 不重複訂單數（來客數） | `DISTINCTCOUNT ( FACT_SALES[ORDER_ID] )` |
| 客單價 | 平均每筆訂單銷售額 = 銷售額 ÷ 訂單數 | `DIVIDE ( [銷售額], [訂單數] )` |
| 銷售數量 | 商品銷售件數 | `SUM ( FACT_SALES[QUANTITY] )` |
| 平均成交單價 | 折扣前平均每件售價 | `DIVIDE ( SUMX ( FACT_SALES, FACT_SALES[UNIT_PRICE] * FACT_SALES[QUANTITY] ), [銷售數量] )` |
| 折扣率 | 折扣金額 ÷ 折扣前金額 | `DIVIDE ( [折扣金額], [銷售額] + [折扣金額] )` |
